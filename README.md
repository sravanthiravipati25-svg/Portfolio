# Ravipati Naga Sravanthi - ASP.NET Core 8 Portfolio

## Run locally

```bash
dotnet restore
dotnet run
```

Open https://localhost:5001 or http://localhost:5000

## Features

- ASP.NET Core 8 MVC
- Razor views
- Bootstrap 5
- Contact form
- Live project links
- Responsive design

## Deployment

Deploy to Render, Azure App Service, or Railway.
